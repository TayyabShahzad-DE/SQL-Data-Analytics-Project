
# 📊 SQL Data Analytics Project

A SQL-based data analytics project built using Microsoft SQL Server. This project focuses on exploring sales data, identifying business trends, analyzing customer and product performance, and generating insights using SQL queries. I built this project to strengthen my SQL skills and practical understanding of data analytics.

## 📦 Technologies

- `Microsoft SQL Server`
- `SQL`
- `SQL Server Management Studio (SSMS)`
- `CSV`
- `Git` and `GitHub`

## 🦄 Features

Here's what you can do with this project:

- **Exploratory Data Analysis**: Explore sales data to understand its structure, key metrics, and business performance.
- **Changes Over Time**: Analyze sales trends across different periods to identify growth and changes in performance.
- **Cumulative Analysis**: Calculate running totals and track business performance over time.
- **Performance Analysis**: Evaluate sales performance and compare products and customers.
- **Data Segmentation**: Group customers and products into meaningful categories for deeper analysis.
- **Part-to-Whole Analysis**: Understand how individual products or categories contribute to overall sales.
- **Customer Report**: Analyze customer activity, purchasing behavior, and sales contribution.
- **Product Report**: Evaluate product performance, sales contribution, and related business metrics.

## 👩🏽‍🍳 The Process

I started by setting up the SQL Server database and loading the sales datasets from CSV files. I then explored the database tables and examined the available data to understand its structure and contents.

Next, I performed exploratory data analysis using SQL queries to investigate key metrics, sales figures, and business trends. This helped me understand the data and identify useful information for further analysis.

After that, I applied advanced analytical techniques, including changes over time, cumulative analysis, performance analysis, data segmentation, and part-to-whole analysis. These techniques helped me examine sales patterns and compare business performance from different perspectives.

Finally, I developed customer and product reports using SQL queries to organize the findings into meaningful insights. I also arranged the SQL scripts in a structured order and documented the project on GitHub for easier navigation and future reference.
